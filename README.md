# 🧮 Flask Calculator

A modern, interactive calculator built using Python, Flask, HTML, CSS, and JavaScript.

## ✨ Features

- Basic arithmetic operations
- Square and cube calculations
- Square root and cube root
- Power calculations
- Modulus and percentage operations
- Calculation history
- Light and dark themes
- Toggleable advanced functions
- Responsive user interface
- Interactive buttons and smooth transitions

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Git and GitHub

### ⚙️ Installation and Setup 

### 1. Clone the repository

```bash
git clone https://github.com/Adityaranjan1234/flask-calculator.git
```

### 2. Open the project folder

```bash
cd flask-calculator
```

### 3. Install Flask

```bash
python -m pip install flask
```

### 4. Run the application

```bash
python app.py
```

### 5. Open the calculator

Visit http://127.0.0.1:5000
